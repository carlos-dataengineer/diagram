# Como contribuir

1. Abra uma issue descrevendo problema ou proposta.
2. Faça alterações em uma branch própria.
3. Preserve a experiência autocontida do editor sempre que possível.
4. Não inclua dados reais, segredos, tokens ou informações pessoais em exemplos.
5. Execute o plano de testes em `tests/manual-test-plan.md`.
6. Envie um Pull Request com contexto, motivação e evidências visuais quando aplicável.
