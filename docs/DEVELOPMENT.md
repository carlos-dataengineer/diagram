# Desenvolvimento

## Requisitos
- Navegador moderno com suporte a SVG, localStorage, File API e APIs padrão do DOM.
- Git para versionamento.

## Desenvolvimento local
Abra `app/index.html` diretamente no navegador. Para testar via servidor local, qualquer servidor estático pode servir a pasta `app/`.

## Diretrizes
- Preserve a execução sem build e sem dependências obrigatórias.
- Não introduza credenciais, tokens ou dados de clientes.
- Mantenha os exemplos demonstrativos fictícios.
- Faça alterações pequenas e documente mudanças de comportamento.
- Teste importação/exportação e operações de edição antes de publicar.

## Verificações recomendadas
- Validar sintaxe JavaScript.
- Testar abertura do HTML em Chromium, Firefox e Safari atuais.
- Testar layout desktop e mobile.
- Verificar que importação inválida falha sem corromper o documento atual.
