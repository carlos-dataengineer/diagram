# Política de segurança

Não publique credenciais, tokens, dados pessoais ou diagramas confidenciais em issues públicas.

Para reportar uma vulnerabilidade, utilize o canal privado de segurança disponibilizado pela plataforma GitHub para o repositório, quando habilitado. Inclua passos de reprodução e impacto, evitando divulgar detalhes exploráveis publicamente antes da correção.
